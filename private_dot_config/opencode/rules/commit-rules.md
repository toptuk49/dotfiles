# Правила написания Git коммитов

- Формат первой строки: `type(scope): краткое описание`. type из набора `feat`, `fix`, `chore`, `docs`, `refactor`, `ci`, `perf`, `test`. scope — по возможности узкий (например `docker`, `profiles`). Строка без подписи, строчными буквами, с большой буквы первое слово описания.
- Если нужно тело коммита: пиши список из пунктов.
- Пункты тела - каждый на отдельной строке через `- `. Текст после `- ` должен идти последовательно, одной непрерывной строкой, без переносов строк внутри пункта и без выравнивания пробелами или `tab`. Не подгоняй длину строк под какую-либо ширину.
- В футере опиши коротко, что дает коммит.
- Футер пиши после пунктов, отделив его от тела пустой строкой.
- Если коммит короткий - пункты тела можно пропустить и написать сразу футер (или вовсе ограничиться первой строкой).
- Язык коммитов по умолчанию английский. Если есть предыдущие коммиты - используй их язык.
